The definitions, ordinary usage examples, parts of speech, and phonetic transcriptions in the generated output are derived from Wiktionary contributors using Wiktextract. Each generated entry includes a `sourceUrl` linking to the corresponding Wiktionary page and its contributor history.

Changes were made: Wiktextract converts Wiktionary markup to structured data, then this processor selects supported languages and fields, normalizes lookup keys, combines entries, limits meanings and definitions, omits sourced quotations and unused fields, and emits hashed JSON shards.
